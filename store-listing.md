# Fiche Play Store — Vision du Ciel (brouillon pour la Console)

## Nom
Vision du Ciel

## Description courte (80 caractères max)
Registre d'identité avec photo et empreinte, 100 % local.

## Description complète
Vision du Ciel est un registre d'identité simple et sécurisé pour Android.

Enregistrez chaque personne avec son nom complet, son type de pièce
d'identité (carte d'identité, passeport, permis de conduire, carte
d'électeur ou autre), son numéro de pièce, son téléphone et sa photo
(appareil photo ou galerie). Chaque fiche reçoit un code unique
(P0001, P0002, …) pour la retrouver en une seconde.

Retrouvez une personne par son code ou par son nom, avec sa fiche
complète et sa photo. Vous pouvez aussi désigner le propriétaire du
téléphone, puis l'identifier en posant son doigt sur le capteur :
le téléphone confirme son propriétaire et affiche sa fiche.

Vos données restent sur votre téléphone : aucune donnée n'est envoyée
sur Internet, aucun compte n'est requis, aucune publicité, aucun traqueur.
La suppression d'une fiche ou la désinstallation de l'application
efface les données.

Interface sombre tech, pensée pour un usage quotidien rapide.

## Catégorie
Outils

## Classification du contenu
Aucun contenu sensible : pas de violence, pas de contenu sexuel,
pas de jeux d'argent, pas de langage grossier. Public : tout public.

## Sécurité des données (à déclarer dans la Console)
- Données partagées avec des tiers : aucune.
- Données collectées hors de l'appareil : aucune.
- Données traitées uniquement sur l'appareil : nom, pièce d'identité,
  téléphone, photo (stockage local de l'application).
- Compte requis : non. Publicités : non. Traqueurs : non.
